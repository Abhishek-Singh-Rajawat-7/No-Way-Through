## 🕹️ Gameplay Overview

The player must explore the environment, search for useful items, and find a way to escape while avoiding a hostile enemy.

Key gameplay elements include:

- Exploring the environment and searching through chests.
- Collecting essential items such as a lantern, gun, and key.
- Using interactive objects to progress through the game.
- Avoiding an enemy that reacts to player activity.
- Finding a way to escape while managing available resources.

## 🤖 Enemy AI & Systems

The enemy uses a **Finite State Machine (FSM)** and Unity's **NavMesh Agent** for navigation and behaviour.

Implemented behaviours include:

- Idle
- Patrol
- Chase
- Attack

The enemy can also react to sounds generated by player actions, such as running, opening chests, and dropping objects.

## ⚙️ Gameplay Mechanics

- **Raycast Interaction:** Interact with objects in the environment.
- **Lantern System:** Use a lantern to navigate dark areas.
- **Weapon System:** Use a limited-use firearm for survival.
- **Item Collection:** Find and collect essential items from chests.
- **Game Flow:** Progress through exploration, survival, and escape scenarios.
